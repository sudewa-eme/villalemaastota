# Property photography

Drop the villa's photographs here using these exact file names. Each one
replaces its illustrative placeholder automatically on the next build.

| File name                  | Photograph                                                    | Used in                                  |
| -------------------------- | ------------------------------------------------------------- | ---------------------------------------- |
| `infinity-pool-sunset.jpg` | Infinity pool at sunset, heart-arch deck, mountain reflection | Hero, gallery                            |
| `villa-aerial.jpg`         | Aerial of the white bungalow, terraces and pool               | Introduction, accommodation, gallery     |
| `estate-overhead.jpg`      | Top-down drone view of the estate and winding lane            | Experiences (forest trails), gallery     |
| `dinner-deck-dusk.jpg`     | Candlelit table for two under the heart arch, blue hour       | Offers & occasions, gallery              |
| `firepit-lounge.jpg`       | Sunken stone fire pit with grey cushioned seating at night    | Dining, gallery                          |
| `pool-deck-reading.jpg`    | Guest reading on a lounger by the pool, yellow blossom        | Accommodation, gallery                   |
| `misty-lawn.jpg`           | White garden chairs on the lawn beneath the misty mountain    | Introduction, experiences backdrop, gallery |
| `living-room.jpg`          | Living room: wingback chair, linen sofa, panelled walls       | Accommodation, gallery                   |

Guidelines: landscape JPEGs at least 2400 px wide (sRGB, quality ~85). Next.js
generates responsive AVIF/WebP sizes automatically. Focal points and alt text
live in `src/content/media.ts`.
